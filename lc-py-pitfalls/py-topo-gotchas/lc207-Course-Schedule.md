1) in_degree[x]：這門課還欠幾個「先修課」
in_degree = 0 代表：現在就可以修
in_degree > 0 代表：還不能修，因為先修還沒完成

2) queue：把「現在就能修的課」放進去
每次從 queue 拿一門課去修，修完後會讓它後面的課少一個先修需求。

---

程式：

(A) 建圖 + 計算 in-degree:
graph[先修課] = [哪些課依賴它]
in_degree[某課] = 有幾門先修課

(B) 把所有 in_degree == 0 的課丟進 queue
所有不用先修的課，先放進「可選清單」。

(C) BFS：一直修「目前可修」的課
1. popleft() 拿出一門現在能修的課 now_pos
2. num_choose += 1：代表我又成功修完一門
3. 看 now_pos 這門課解鎖了誰（graph[now_pos] 裡的課）
4. 對那些課：in_degree -= 1（少欠一個先修）
5. 如果變成 0：代表現在也能修了 → 丟進 queue

(D) 最後判斷能不能修完
1. 如果你最後「修到的課數」等於總課數 → 全部都被順利解鎖 → 沒 cycle
2. 如果修不到那麼多 → 一定有一群課互相卡住（cycle），永遠沒有 indegree 變 0 → 不能修完
